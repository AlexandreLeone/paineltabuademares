Versão vitalícia, sem propaganda

R$ 36,50 · pagamento único, vale para sempre neste aparelho

Com o celular em pé, o letreiro do app começa pelo endereço do site. Na versão vitalícia ele não aparece mais. Isso vale para o app instalado pelo APK no Android e para o app web no iPhone. O painel de LED físico não tem propaganda.

  2. Pague R$ 36,50 por Pix, com o QR code ou o "Pix copia e cola":
  3. Envie o comprovante por e-mail. O botão abaixo abre o e-mail já com o código do aparelho no assunto; é só anexar o comprovante do Pix.

  4. Pronto. Assim que o pagamento for confirmado (em até um dia útil), a propaganda some sozinha na próxima vez que o app sincronizar. Para conferir na hora, toque em Ajustes → Já paguei: verificar a liberação agora.

Se trocar de celular ou reinstalar o app, o código muda. É só nos mandar o código novo junto com o comprovante antigo, e liberamos de novo sem custo.
